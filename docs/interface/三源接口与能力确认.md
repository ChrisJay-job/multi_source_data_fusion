## 2. 标准 Observation（后端→算法）

### 2.1 逐字段

| 字段 | 类型／单位 | 坐标／时间定义 | 范围／哨兵 | 必填 | 缺失／非法 | 当前实现 |
|---|---|---|---|---|---|---|
| observationId | string | — | 会话内唯一 | 是 | 拒收 | 已实现 |
| source | enum `rid\|spectrum\|radar`（或历史别名经适配） | — | — | 是 | 拒收 | 已实现 |
| detectorId | string | 设备／通道身份 | 非空 | 是 | **拒收**（不默认 DET） | 已实现 |
| sourceTrackId | string | 来源侧航迹键 | 非空 | 是 | **拒收**（不自动造号） | 已实现 |
| aircraftId | string\|null | 可信 SN | — | 条件（RID／频谱可信时） | 仅航迹号关联 | 已实现；导入默认不把 raw id 当 SN |
| measurementTime | RFC3339 **带时区** | 测量时刻 | — | 是 | 无时区须显式假设档 | 已实现；`Asia/Shanghai` 等命名时区已支持 |
| receivedAt | RFC3339\|null | 到达／入库时刻 | — | 否 | 当前实现：文件无列时仍写入 measurementTime 并在 qualityFlags 标 `receivedAt_proxied_from_measurement`（代理，非真实延迟证据） | 已实现（代理行为）；设备真实 receivedAt **待确认** |
| timeBasis | string | 时间语义 | — | 否 | 默认 measurement | 已实现 |

| altitude | m\|null | 依 altitudeDatum | 哨兵候选 **-2**（**待确认**，不定性） | 否 | 降级 unknown，不补 0 | 已实现降级 |
| altitudeDatum | string\|null | 高度基准 | — | 否 | 显示缺语义 | 透传 |
| speed | m/s\|null | 对地速度 | — | 否 | 忽略 | 映射透传 |
| heading | deg\|null | 运动航向（非测向） | — | 否 | 频谱非法置空 | 已实现 |
| verticalSpeed | m/s\|null | — | — | 否 | 忽略 | 映射透传 |

正例：`docs/interface/examples/observation_ok.json`  
反例：`docs/interface/examples/observation_bad_timezone.json`

### 2.2 来源差异摘要

- **RID**：通常带 SN；位置噪声小。
- **频谱**：可能带 SN；位置噪声大；航向可能不可信。
- **雷达**：通常无 SN；依赖 `detectorId+sourceTrackId`；换号须分段。

## 3. 算法输出／事件／错误

### 3.1 ProcessResponse（见 OpenAPI）

| 字段 | 含义 |
|---|---|
| watermark | 事件前沿。**realtime**：提交水位推进到 `max(prior, processingTime−reorder_window)`（空批亦同口径，不以“缓冲为空”改为 processingTime）。**replay**：按虚拟测量时钟／批处理规则推进，不套用 realtime 的 wall-clock 减窗公式。 |
| tracks[].stateTime | 滤波状态时间 |
| tracks[].displayStateTime | 展示用时间（可等于预测外推时刻） |
| tracks[].positionMode | 实际为 `measured_assisted`／`predicted`／`stale`（不是笼统 measured） |
| tracks[].positionSource | 最近更新来源 |
| tracks[].sources | 活跃来源类型枚举 |
| tracks[].sourceTracks[].bindingStatus | `candidate`\|`confirmed` |
| rejected[] | 单条观测拒绝，不导致整批失败（契约内） |
| events[] | `source_bound`／生命周期等 |
| error | 批级错误码；空为成功 |

### 3.2 错误与幂等

| 码／HTTP | 语义 |
|---|---|
| 409 | batch_id_conflict／session_mode_conflict／idempotency_expired／observation_id_conflict |
| 400 | invalid_processing_time／processing_time_not_monotonic |
| 500 | batch_rollback（状态已恢复） |

会话与时钟：单进程 `SessionStore`；`processingTime` 须单调；realtime 按 receivedAt 缓冲，replay 按 measurementTime。

## 5. 验证台 API

| 路径 | 用途 |
|---|---|
| `POST /v1/fusion/process` | 真实融合核心 |
| `GET /v1/workbench/scenarios` | 预置＋已存场景列表 |
| `GET /v1/workbench/scenarios/{name}` | 场景定义 |
| `POST /v1/workbench/scenarios/save` | 保存编辑后场景 |

| `POST /v1/workbench/import/preview` | 预览（不定义正式数据集） |
| `POST /v1/workbench/run/import` | 正式回放（重解析原文） |
| `GET /v1/workbench/datasets/{id}/observations` | 观测分页窗口 |
| `GET /v1/workbench/local-data` | 列出 `data/` |
| `POST /v1/workbench/run/local` | 受限目录回放 |

OpenAPI：`docs/openapi.yaml`（含 workbench 路径）。静态文档与实现不一致时以代码＋实测为准并修订文档。

鉴权：默认本机回环；上传 `data/uploads/`；禁止任意绝对路径与 `..` 穿越。
