# 需求：RID／频谱／雷达三源融合 MVP

来源：`prompt/gpt/Cursor_TASK-001_三源融合MVP_执行指令.md`（2026-10-17）。

## 范围

- 必须：RID（`tj-rid`）、频谱（`tj-pp`）、雷达（`tj-leida`）
- 不做：ADS-B、光电、射频指纹、欺骗定性、五源、复杂 JPDA/MHT

## 关联规则（摘要）

1. RID/频谱在可信 SN 一致时身份锚定，并做时间/位置合理性检查。
2. 雷达仅有设备内航迹号；按时间、位置、运动关联；换号可有界续接，证据不足则新建。
3. 有效及时 RID 优先作位置主来源。
4. 短时全失联有限预测（`predicted`），不刷新 `lastObservedAt`。
5. 交叉近距不强绑，允许歧义与未匹配。

## 接口

- `GET /health`、`GET /ready`
- `POST /v1/fusion/process`：session 串行、批幂等、可空批推进水位

## 验收边界

- 合成场景 T01–T12 可断言行为
- 真实数据：解析率/拒绝/航迹行为；无同步真值时 **不** 报关联准确率或现场精度 PASS
