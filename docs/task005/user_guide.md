# TASK-005 可解释验证台用户指南（Round1 更新）

## 一条线代表什么

- **真值已飞**：仿真真值折线（评估外侧），不是设备轨迹。
- **融合提交历史**：主位置来源 KF 已提交估计点连线。
- **当前位置**：当前播放时刻估计。
- **预测历史**：虚线，由状态外推，不是新测量。
- **RID/频谱/雷达观测连线**：按时间顺序连接的离散观测，不是额外实测。

## 为什么抖动

观测噪声与仿真 `pos_noise_m` 造成点位抖动；不等于现场精度。

## 为什么出现预测

无新鲜主源测量时引擎可外推；realtime 重排窗口内“播放时刻预测”不等于漏接。

## 同一目标多个来源怎么合并

主位置来源优先（RID 新鲜时优先）；其他源可能仅绑定。候选距离若引擎未输出则显示「当前未输出」，前端不推测。

## 单源为什么也有融合目标

引擎为每条关联航迹分配 fusionId；单源也会形成目标。

## 怎样识别错合并 / 拆轨 / 换 ID

看右侧「异常」与 `metrics_display`：误合并、重复目标、错绑、ID交换计数；硬错误保留原始 FAIL，能力边界说明不覆盖失败。

## 身份模式

- **both_id**：双方可靠不同身份（同源组合）。
- **both_anon**：同上源组合，关闭 emit_aircraft_id。
- **mixed**：身份机 + 匿名雷达（明确标注，不作公平身份对照）。

传感器页可勾选各源「上报身份」；导出/重导保留。

## 指标定义（摘要）

| 指标 | 含义 | 分母/规则 |
|---|---|---|
| 目标数 | 末快照 tracks | 末快照 |
| 误合并/拆轨/错绑 | 评估器列表长度 | 整次运行 |
| 关联覆盖率 | 已匹配真值实体/期望稳定实体 | 缺期望则不可计算 |
| 二维 RMSE | 已提交估计 vs 真值 | 需 fusion_to_truth+timeline；否则不可计算（≠0） |

## 时钟与计数

播放时刻 / watermark / 最后实测 分列。快照帧索引不是已处理批数；缺可靠计数标「未提供」。
