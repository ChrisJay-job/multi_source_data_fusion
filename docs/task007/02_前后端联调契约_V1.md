# TASK-007 联调契约实测状态

目标契约原文仍是执行包 `02_前后端联调契约_V1.md`。下表是本工作区当前实现的实测状态。未实现的字段不标成可用。

| 项 | 状态 | 说明 |
|---|---|---|
| `GET /health` | 已实现 | 存活检查 |
| `GET /ready` | 已实现 | 返回 `supportedProfiles=["legacy","multisensor-v1"]`、`reorderWindowSeconds=2`、`stateOwner=single-process-SessionStore`，以及正在运行的 `configSha256` / `multisensorModuleSha256` |
| `POST /v1/fusion/process` | 已实现 | 缺省 `fusionProfile` 仍走 legacy。显式 `multisensor-v1` 走新引擎 |
| `POST /v1/fusion/replay` | 已实现 | 按绝对时刻排序后在临时会话回放。不写回实时 `MS_STORE`，不能用来恢复重启前的实时会话。内部逐帧不占用公开幂等名额。业务失败返回非 2xx，其中容量类错误为 409 |
| 幂等窗口 | 已实现 | 公开 `POST /v1/fusion/process` 的 realtime 与 replay 均生效。窗口内旧 batch 返回原响应或 `idempotency_expired`；同 batch 不同内容 409。记住的 batch 数达到 `max_idempotency_ids` 时，新 batch 返回 409 `idempotency_capacity`。仅内部临时回放任务可选择不保留逐帧幂等 |
| `POST /v1/fusion/reset/{sessionId}` | 已实现 | 只删除该会话，legacy 与新剖面会话都会删 |
| 会话固定 profile / mode | 已实现 | 冲突返回 409。不支持的 profile 返回 422 |
| 相同 batch 重试 | 已实现 | 响应与第一次相同，`snapshotSeq` 不增加 |
| 同 batch 不同内容 | 已实现 | 409 |
| 观测内容冲突 | 已实现 | 409 |
| 超限 | 已实现 | 实时单请求 5000 条、离线 20000 条返回 413，不截断后假装成功 |
| 处理失败回滚 | 已实现 | 500 `batch_rollback` |
| 空 tick | 已实现 | 空 `observations` 推进时钟和生命周期，不重置会话 |
| 未来时间 / 越过前沿的迟到观测 | 已实现 | 拒绝并给出原因，不推进到该未来时刻 |
| 无 SN 多设备关联 | 已实现 | 合成样例：六设备收敛为一条 `multi_sensor_estimate` 航迹 |
| 位置估计 | 已实现 | 匿名且质量可用的源进入常速度卡尔曼更新。`positionStdM` 是米制标准差，滤波使用方差 `std^2`。默认噪声未标定 |
| 有 SN | 已实现 | 补上 `aircraftId` 后保持 `fusionId`，`fusionMethod` 转为 `primary_source` |
| 轨迹增量 | 已实现 | 单次响应返回本批全部已提交点，不按 500 截断。`committedHistory` 只保留最近 80 点并标记 `history_capped`。重试的 `pointId` 不变 |
| 扫描竞争 | 已实现 | 同一个 `detectorId` + `scanId` 先整组一对一预留，再按测量时间应用，不把滤波时钟拨回。扫描释放后 4 秒内，另一个设备局部编号返回 `scan_closed`。同一局部编号可继续，窗口过后扫描号可复用。没有 `scanId` 时，同一探测器 50 毫秒桶内的观测互相竞争。生成的局部编号不是设备身份 |
| 身份连续 | 已实现 | 波门内唯一同号航迹优先于更近的匿名航迹。越波门的同号不抄到匿名航迹。同号含糊返回 `identity_ambiguous` |
| 内存状态 | 已实现且有限制 | 单进程内存。重启、reset、过期后会话消失。后端需自行保存原始输入再回放。未接 Redis |
| 开发地址 | 仅本机 | `http://127.0.0.1:18089` 只给本机。远端联调要用可达地址 |
| 真实三源同一架机 | BLOCKED | 现有 JSON 两段时间不重叠，不是同机真值 |
| 现场鸟/无人机识别 | NOT_TESTED | 不输出 `confirmed_drone` |
| 约 2GB SQL | NOT_TESTED | 本任务不扫描 |
| Asia/Shanghai | 未确认 | 仍是设备时区假设 |
| 离线一定更准 | 不成立 | 离线只是排序回放。实时超出重排窗的点会丢，离线可以重排 |
| 回放摘要 | 已实现 | `valid` 是输入减去被拒绝的观测号，`processed` 是已完成帧的行数，`unprocessed` 是尚未完成的行数。中止时 `note` 不声称全部观测已处理 |

算法版本字符串仍是 `mvp-0.1.0`。运行中的配置和 `multisensor.py` 以 `/ready` 的两个 SHA-256 为准。
